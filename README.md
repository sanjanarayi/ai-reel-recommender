# 🧠 ReelMind AI

### AI-Powered Personalized Tech Reel Recommendation System

ReelMind AI analyzes user interactions such as **likes, watch percentage, replays, topics, and categories** to understand their broader interests and recommend relevant technology content.

Unlike simple keyword-based systems, ReelMind AI uses AI-powered reasoning to provide personalized recommendations while reducing **repetition, hype, and misleading content**.

## 🚀 Features

- 🧠 AI-powered recommendations
- ❤️ Like and engagement tracking
- 👁️ Watch percentage analysis
- 🔄 Replay behavior analysis
- 🎯 Personalized tech content
- 🚫 Hype/clickbait detection
- 🗄️ MongoDB database

## 🛠️ Tech Stack

- **Frontend:** HTML, CSS, JavaScript
- **Backend:** Python, Flask
- **Database:** MongoDB
- **AI:** OpenAI API
